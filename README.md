# Delnavazan

Unified product repository for the Delnavazan academy platform and WordPress frontend.

## Active components

- `platform/` — canonical Delnavazan Platform plugin and backend/application services.
- `theme/` — Delnavazan WordPress theme and user-facing frontend.
- `deployment/` — deployment notes and staging/production handoff guidance.
- `legacy-review/` — migration notes for older Delnavazan plugins that are not active monorepo components.

## Source of truth

New product work should be committed here. The historical component repositories remain available as rollback/reference sources while staging is completed.

## Staging

Current visual and functional target: `https://staging.delnavazan.com`.
Public `delnavazan.com` remains on the old production host until explicit cutover approval.
